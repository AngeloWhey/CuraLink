# Open the packaged receiver in ADS

Open `ads/MyWorkspace_wrk` in ADS. Choose **Library View**, expand **MyLibrary_lib → CuraLink_RX_BAS4002A_HB → schematic**, and open the schematic. Refresh the workspace tree if it was already open. Double-click the schematic view of **BAS4002A_SOT143** in the same library to inspect the device internals. These are native, editable OpenAccess cells with named nets and local model parameters. The earlier receiver schematic cells are preserved. [Workspace](../../../../ads/MyWorkspace_wrk/) · [Receiver schematic PDF](CuraLink_RX_BAS4002A_HB.pdf) · [Four-pin package subcircuit PDF](BAS4002A_SOT143.pdf)

The top cell represents the fixed published coil pair, both matching networks, the floating receiver, one Infineon BAS4002ARPPE6327HTSA1 and its reservoir. In the subcell, package pins **2 and 3** are the floating AC feed, **1** is DC return and **4** feeds the positive reservoir. Each package lead has assumed series parasitics and the four internal junctions use the project's typical 25 °C fit. The schematic uses the package as one component. The manufacturer specifies terminal roles and device limits; the parasitic and junction fit require assembly correlation. [Infineon BAS4002A datasheet](https://www.infineon.com/assets/row/public/documents/24/49/infineon-bas4002aseries-ds-en.pdf) · [Device fit, receiver assumptions and alternatives](../receiver-ic-review-2026-11-22/README.md)

Run the HB controller at **13.56 MHz, order 31**. The default `Pin_dBm=25` represents 316.2 mW available from the matched 50 Ω generator. `Iload_mA=24` sets a voltage-compliant load at the raw output. The 1 µF reservoir has modeled series parasitics. The TX network has 60 pF series and 375 pF shunt; the floating RX network has 1 nF series and 680 pF shunt. Capacitor series loss assumes Q = 500 at the carrier. Named nets bridge the schematic groups. Use the matching network output differential `AC1−AC2` for the bridge input.

Its mean raw voltage agrees with the separately generated operating-matrix deck within 0.17 µV at this point. Plot `Vraw_DC`, `Praw_mW`, `eta_available` or `Z_RX_fund` in the ADS data display, or open the exported data below on a laptop without ADS. The top cell stops at the reservoir and its load. Use the [RF/DC operating matrix, TVS, TI regulator and delayed-load evidence](../receiver-ic-review-2026-11-22/README.md) to evaluate the 5 V board interface and light-load stress.
