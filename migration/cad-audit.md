Recorded **2026-11-22**, America/New_York. This is an initial file inventory and portability audit, not new electrical verification or a final publication manifest. Packaging can subsequently add files. [Machine-readable inventory](cad-audit.json) preserves the source paths, sizes, hashes for secondary-copy differences, dependency findings and scan boundaries.

The main source is `Documents/ChatGPT/curalink`; the older `Documents/projects/curalink` copy also contains the real ADS workspace. The latter workspace is handled by the separate ADS migration task. Outside ADS, the older copy contributes eight unique CSV exports and the two scratch recovery ZIPs plus their manifest. Three design documents differ from the initial canonical snapshot and should be retained as labeled historical copies rather than replacing the engineering record. The migrating README and AGENTS instructions were later updated separately.

The active mainboard has **17 KiCad schematic files**, its `.kicad_pro` and `.kicad_pcb`, one project symbol library and **30 local footprint types**. Both project library tables use `${KIPRJMOD}`. Optional standard STEP models use `${KICAD9_3DMODEL_DIR}` from a KiCad 9 installation. No native Altium project/schematic/PCB/library files were found in either source project or the explicitly listed bounded Keysight/KiCad/LTspice/GitHub/Ansoft/ADS-workspaces folders. This does not assert that no such files exist elsewhere on the machine.

Most authored LTspice decks resolve bundled models. Eighty-seven older fixture includes require running from the corresponding parent directory: the AFE vendor-model studies from `hardware/rev-a/afe`, and historical R511 studies from `hardware/rev-a/ltspice/power`. Nine unresolved include entries occur only in the retained manufacturer PSpice demonstration directories and refer to PSpice standard libraries or absent demonstration netlists; they do not invalidate the separate authored LTspice fixtures.

The historical `output/curalink-rev-a-handoff.zip` is **113,440,355 bytes**, above GitHub's ordinary single-file limit, so publication must preserve it through LFS or documented split storage. Simulation raw files and tables are useful evidence. The Java runtime and downloaded routing-tool archives in `tmp/pcb-tools` are installed tool caches; 142 inaccessible entries belonged to that excluded runtime, not CAD sources. All four user-supplied CuraLink pasted-context attachments remain available at their recorded source paths and should be labeled historical context when imported.

Computer-path changes are limited to six LTspice runners, three runner-generating Python templates and the critical-footprint verifier. They now accept the relevant environment overrides and installed-tool locations for the new account. [Runner portability checks](runner-portability.json) record PowerShell parsing and Python AST checks. No CAD generator, simulator or footprint geometry verifier was executed during these changes; circuit values, case lists, hidden execution and working directories were preserved.
