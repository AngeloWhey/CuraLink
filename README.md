# CuraLink

CuraLink is an eight-channel, benchtop neural-like signal acquisition prototype. The project brief and current planning documents live in `outputs/`.

The file `outputs/CuraLink-8-channel-neural-input-fanout-test-fixture.md` is a user-provided reference for a separate passive AWG-to-eight-channel test fixture. It is intentionally kept as a text design note and is not fabrication-locked.

This repository is for the CuraLink engineering work described in `outputs/CuraLink-project-brief.md`. Treat all provisional values as assumptions until they are verified by simulation, datasheets, or measurement.
